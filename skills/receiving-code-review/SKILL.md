# Receiving Code Review

Responds to code review feedback constructively. Accepts suggestions, improves code quality, and learns from each review cycle.

## When to Use
- Code review comments have been submitted on your work
- Need to understand and address feedback

## Guidelines
- Read all comments before responding
- Assume good intent — reviews improve code quality
- For each comment: fix, explain, or discuss
- If you disagree, explain your reasoning with evidence
- Thank reviewers for catching issues
- Apply fixes promptly to keep cycle short
- Extract patterns you can apply proactively next time
